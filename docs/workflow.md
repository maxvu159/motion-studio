# Workflow

```
 idea + brand kit + claims source
          │
   0 INTAKE ── brief.md ───────────────────────────────┐
          │                                              │ ask only what is missing
   1 REFERENCE (optional) ── ref_teardown → sheets → genre, grammar, keywords
          │
   2 PLAN ── storyboard in bars/beats + copy, claims traced ──▶ USER APPROVES
          │
   3 MUSIC ── licence? → beatmap → structure → scene layout on bars → music_edit if needed
          │
   4 ASSETS ── brand kit, glyph_check, footage-hunt (subagents, manifests), words.py
          │
   5 BUILD ── template + project scenes, all timing in beats, data-t targets
          │
   6 STILLS ── key frames + every click → sheet → LOOK → fix ──┐ (loop until clean)
          │                                                     │
   7 PREVIEW 720p ── mix → mux → sync_check PASS → ~/Downloads ─┴─▶ USER REVIEWS
          │
   8 FEEDBACK loop ──▶ FINAL 1080p/2K ──▶ notes.md (decisions, measurements, gotchas)
```

## Checklists

**Intake** — goal and audience · platform + aspect + length · brand kit or design system · product
source (repo / screens) · claims source · music situation (licensed? internal only?) · deadline · who
approves.

**Plan** — table: time | bars/beats | scene | on-screen copy | source of the claim | music moment.
Mark planned/roadmap items as such. Note risky claims for the user.

**Stills** — text overflow · contrast on background · brand font on every element (labels, numbers) ·
no fallback glyphs · cursor on target at every click · copy matches claims source · nothing third-party
or confidential on screen.

**Delivery message** — file path, resolution, length; what changed; what was verified and how (stills,
sync table, LUFS); what was not verified (listening); open questions.
